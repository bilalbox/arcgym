# Case File alongside Rapid Fire

ArcGym supports two drill formats: **Rapid Fire** (daily streak, high-tempo decision reps) and **Case File** (Evaluation-scale practice with a Brief, Probe Budget discovery across three Stations, then confidence-gated recommendations).

ADR 0001's sole-format constraint is superseded for Case File only. Lesson, Currency, Scenario, Board Probe, and Diagram-as-separate-format remain retired. Case Files are not mixed into the daily three-rep Rapid Fire streak; they use a separate **Cases** entry. Every Case File has a Brief and exactly three Stations.
