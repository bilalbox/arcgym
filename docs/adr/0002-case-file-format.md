# Case File alongside Rapid Fire

ArcGym supports Rapid Fire (daily streak, high-tempo decision reps) and **Case File** (Evaluation-scale practice with a Brief, Probe Budget discovery across Stations, then confidence-gated recommendations). A third format, **Troubleshooting**, is documented in ADR 0004; this ADR remains Case File–only.

ADR 0001's sole-format constraint is superseded for Case File (and later Troubleshooting). Lesson, Currency, Scenario, Board Probe, and Diagram-as-separate-format remain retired. Case Files are not mixed into the daily three-rep Rapid Fire streak; they use a separate **Cases** entry. Every Case File has a Brief and **at least three** Stations (Harborline uses three; deeper lifecycle cases may use more).
